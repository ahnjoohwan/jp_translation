## 변경점

- **진입점 추가**: `app.py`(Streamlit). 이미지 다중 업로드 → 언어 선택(multiselect)
  → 번역 실행 → 엑셀+주석이미지를 ZIP으로 `st.download_button` 다운로드.
- **코어 인메모리화**: `translate.py`에 `run_pipeline(images, product_name, target_langs, progress)`
  신설. `images=[(파일명, PIL.Image)]`를 받아 OCR→번역→주석합성→엑셀을 인메모리(BytesIO)로
  처리해 `{'excel': bytes, 'annotated': bytes, 'count': int}` 반환. 디스크 의존성 제거.
  - `ocr_image()`가 경로 대신 **PIL 이미지**를 받도록 변경(업로드 파일은 경로가 없음).
  - `create_excel()`이 `output`(경로/BytesIO 모두 허용) + `target_langs` 인자를 받아
    **선택 언어 수만큼 번역 컬럼**을 동적 생성. 기존 '번역 (일본어)' 고정 컬럼 대체.
  - `translate_all_langs(texts, target_langs)` 언어 인자화.
  - 파일명 숫자 정렬 로직을 모듈 레벨 `filename_sort_key()`로 추출(업로드 정렬에 재사용).
- **CLI 회귀 유지**: `process_product`·`main_single`은 `run_pipeline`을 호출하도록 정리.
  (이 과정에서 `main_single`의 `translate_batch` 인자 누락 잠재버그 해소)
- **키 비밀값 분리**: `config.py`가 환경변수 → `st.secrets` 순으로 키를 읽음(하드코딩 제거).
  `.streamlit/secrets.toml`(gitignore) + `secrets.toml.example`(템플릿) 추가.
- **배포 파일**: `requirements.txt`에 streamlit 추가, `.gitignore`(secrets/input/output/캐시),
  `README.md`(로컬 실행·Streamlit Cloud 배포·시크릿 설정 안내).

## 이유·맥락

- 기존엔 로컬 CLI로 본인만 사용 → 팀원도 URL로 쓰게 하려는 요구.
- 제품 1개가 이미지 20~24장이라 처리에 수 분 소요. Vercel 서버리스는 실행시간 제한으로
  중간 끊김 위험 → 실행시간 제한이 없고 GitHub 연결·업로드/다운로드 내장인
  **Streamlit Community Cloud**를 선택.
- 키가 `config.py`에 평문이었음(아직 git 미추적이라 외부 노출은 없었음). GitHub push 시
  노출을 막기 위해 비밀값으로 분리.

## 영향 / 후속

- 외부 API는 그대로 **Naver CLOVA OCR(유료) + DeepL Free(월 50만 자)** 2종.
- 배포 시: GitHub repo(개인 vs 회사 선택) → Streamlit Cloud Secrets에 키 입력 →
  회사 자료면 Private + 허용 계정 지정.
- DeepL Free 한도는 팀 공유 시 소진 주의(초과 시 Pro 전환 검토).
