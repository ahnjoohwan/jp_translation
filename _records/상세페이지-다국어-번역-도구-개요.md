## 무엇인가
제품 상세페이지 이미지의 텍스트를 OCR로 추출하고 번역하는 도구.

## 핵심 구성
- `translate.py` — 진입점. Naver CLOVA OCR로 텍스트 추출 + DeepL API로 번역.
  - 배치 모드: `input/<제품명>/` 폴더 전체 처리 → `output/<제품명>/<제품명>_translation.xlsx` 생성.
  - 단일 이미지 모드: `python translate.py input/제품명/이미지.jpg`.
- `config.py` — `TARGET_LANGS`로 번역 언어 지정 (예: `JA`, `ZH`, `EN-US`).

## 산출물
- `output/<제품명>/<제품명>_translation.xlsx` (번역 표), `<제품명>_annotated.jpg` (주석 이미지).

## 영향 / 후속
- OCR/번역 API 키 의존 → 키 관리 및 비용 고려.
